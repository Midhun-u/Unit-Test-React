# Unit Test in React js
This repository is for learning unit test in react using vitest and react testing library. In this tutorial i have implemented testing both util functions and components

# Technologies
* React js
* Bun js
* Vitest
* React Testing Library
* Git
* Github

# Installing 
```bash
git clone https://github.com/Midhun-u/Unit-Test-React.git
cd Unit-Test-React
```
```bash
bun install
bun run dev
```
```bash
bun run test
```
